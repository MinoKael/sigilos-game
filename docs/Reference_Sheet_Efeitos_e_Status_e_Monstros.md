# Guia de referência — Efeitos, habilidades e status

Este guia descreve os efeitos que uma habilidade pode aplicar, quem pode ser afetado, como os valores são calculados e o que cada status faz. Os nomes técnicos entre parênteses são os identificadores usados pelo editor.

## 1. Como uma habilidade funciona

Uma habilidade é uma sequência de efeitos executados **na ordem em que aparecem**. Cada efeito define:

- **Tipo:** o que acontece, como causar dano, curar ou aplicar um status.
- **Alvo:** quem recebe o efeito.
- **Condição de abate (`onKill`, quando usado):** o efeito só acontece se a habilidade já tiver derrubado alguém.

Nem todo tipo de efeito aceita todos os alvos ou todos os campos. A aba **Validação** do editor indica combinações incompatíveis e campos que não são utilizados. Os botões de tipo no editor inserem um modelo inicial do efeito.

## 2. Alvos disponíveis

| Alvo no editor | Quem é afetado |
|---|---|
| `Target` | O inimigo escolhido como alvo da habilidade. |
| `AllEnemies` | Todos os inimigos que ainda estão de pé. |
| `Self` | Quem está usando a habilidade. |
| `LowestAlly` | O aliado de pé com o menor valor da característica escolhida. Por padrão, é a menor fração de Vida restante. |
| `AllAllies` | Todos os aliados de pé, incluindo quem usa a habilidade. |
| `HighestAlly` | O aliado de pé com o maior valor da característica escolhida. Por padrão, é a maior fração de Vida restante. |
| `RandomAlly` | Um aliado de pé escolhido aleatoriamente. A escolha é feita uma vez por habilidade; efeitos seguintes que usem esse alvo escolhem o mesmo aliado. |
| `RandomEnemy` | Um inimigo de pé escolhido aleatoriamente, esteja ele Oculto ou não. A escolha é feita uma vez por habilidade. |

Em `LowestAlly` e `HighestAlly`, a característica usada para comparar pode ser configurada. Consulte **Opções de comparação**.

## 3. Tipos de efeito

### Dano (`Damage`)

Causa dano. Por padrão, o cálculo usa o Ataque de quem lança a habilidade, mas pode ser configurado para usar outro atributo ou uma fórmula personalizada.

**Campos principais**
- **Potência (`power`):** multiplicador do atributo usado. Por exemplo, `3.5` significa 350%.
- **Golpes (`hits`):** quantidade de golpes. Em cada rodada de golpes, todos os alvos selecionados são atingidos.
- **Ignorar Defesa (`ignoreDefense`):** fração da Defesa ignorada, de 0 a 1.
- **Dreno (`drain`):** fração do dano causado que retorna como Vida para quem ataca, de 0 a 1.
- **Atributo-base (`stat`):** substitui o Ataque pelo atributo indicado.
- **Termos adicionais (`plus`):** valores de outros atributos somados ao cálculo.
- **Multiplicador condicional (`factor`):** ajusta o resultado conforme uma característica, como a Vida restante ou a quantidade de aliados vivos.
- **Escala por Velocidade (`speed`):** ajusta o resultado usando a Velocidade.
- **Dano fixo (`fixed: true`):** não considera Defesa, elemento nem crítico. Modificadores que alteram o dano recebido pelo alvo ainda se aplicam.

Cada efeito de dano é um golpe independente. Por exemplo, para fazer três golpes normais e depois um golpe que ignora Defesa, use dois efeitos de dano separados.

### Cura (`Heal`)

Recupera Vida com base, por padrão, na Vida máxima do alvo. A **Ferida** impede a cura.

**Campos principais**
- **Potência (`power`):** fração da Vida máxima do alvo. Por exemplo, `0.15` significa 15%.
- **Quantidade (`count`):** cura apenas os N alvos mais feridos. `0` ou campo ausente significa todos.
- **Atributo-base, termos adicionais, multiplicador condicional e escala por Velocidade:** podem alterar o cálculo, conforme descrito em **Como os valores são calculados**.

### Escudo (`Shield`)

Cria um escudo calculado, por padrão, a partir da Vida máxima de quem lança a habilidade. Escudos **não se acumulam**: permanece o maior escudo. O status **Karma** impede a aplicação de escudo.

**Campos principais**
- **Potência (`power`):** fração da Vida máxima de quem lança.
- **Duração (`turns`):** quantos turnos dura.
- O cálculo também pode usar atributo-base, termos adicionais, multiplicador condicional e escala por Velocidade.

### Aplicar status (`Status`)

Tenta aplicar um status positivo ou negativo ao alvo.

- **Status (`status`):** qual status aplicar. Consulte a lista em **4. Status disponíveis**.
- **Chance (`chance`):** probabilidade de aplicação, de 0 a 1.
- **Duração (`turns`):** duração em turnos do alvo.

Status negativos podem ser impedidos por **Imunidade** e **Resistência**. Status positivos podem ser impedidos por **Karma**.

### Ímpeto (`Impeto`)

Adiciona ou remove pontos de Ímpeto. Um valor negativo atrasa o Ímpeto do alvo.

- **Quantidade (`power`):** pontos de Ímpeto a adicionar ou remover.
- **Chance (`chance`):** chance de sucesso, de 0 a 1; só é usada ao atrasar o Ímpeto de um inimigo. O atraso também está sujeito à Resistência.

### Purificar (`Cleanse`)

Remove de cada alvo um efeito negativo: especificamente, o efeito negativo mais antigo. Não exige campos adicionais além do alvo.

### Roubar efeito positivo (`StealBuff`)

Tenta roubar o efeito positivo mais recente de cada alvo e transferi-lo para quem lança, mantendo a duração restante.

- **Chance (`chance`):** probabilidade de roubo, de 0 a 1.
- **Somente um status (`onlyStatus`):** opcional; restringe o roubo a um status específico.
- **Alternativa de Ímpeto (`fallback: true`):** se o alvo não tiver efeito positivo, rouba Ímpeto.
- **Quantidade de Ímpeto (`power`):** no caso alternativo, define quanto Ímpeto roubar; `0` significa todo o Ímpeto do alvo.

Este efeito só aceita `Target`, `AllEnemies` ou `RandomEnemy`.

### Bônus por efeitos (`BonusPerStatus`)

Conta os efeitos presentes nas unidades escolhidas e concede um bônus por efeito contado.

- **De quem contar (`from`):** define quais unidades serão examinadas.
- **Quais efeitos contar (`scope`):** todos, apenas positivos ou apenas negativos.
- **Somente um status (`onlyStatus`):** opcional; conta apenas um status específico.
- **Tipo de bônus (`bonus`):** dano, cura ou Ímpeto.
- **Valor por efeito (`power`):** bônus concedido para cada efeito contado.

O bônus de dano e de cura afeta os efeitos seguintes da mesma habilidade. O bônus de Ímpeto é aplicado imediatamente aos alvos do efeito.

### Alterar duração (`ChangeDuration`)

Aumenta ou reduz a duração dos efeitos que o alvo já possui.

- **Turnos (`turns`):** quantidade somada à duração. Valor positivo prolonga; valor negativo encurta. Efeitos cuja duração chega a zero são removidos.
- **Quais efeitos (`scope`):** todos, apenas positivos ou apenas negativos.
- **Somente um status (`onlyStatus`):** opcional; limita a alteração a um status.
- **Chance (`chance`):** probabilidade de a alteração ocorrer, de 0 a 1.

A duração não pode ser reduzida para zero e mantida ativa: ao chegar a zero, o efeito é removido.

### Nivelar Vida (`EqualizeHealth`)

Coloca todos os aliados de pé com a mesma **fração de Vida**: a média das frações atuais da equipe. Quem tinha mais Vida perde parte dela, sem ser derrubado; quem tinha menos recebe cura. A cura pode ser bloqueada por **Ferida**.

Este efeito só aceita `AllAllies`.

### Recuperar Vida da equipe (`HealTeam`)

Cura os aliados mais feridos, usando a fração de Vida como critério. Pode ser aplicado a `AllAllies`, `LowestAlly` ou `Self`.

- **Potência (`power`):** fração da Vida máxima recuperada por alvo.
- **Quantidade (`count`):** número de aliados a curar; `0` significa todos.
- O cálculo pode usar atributo-base, termos adicionais, multiplicador condicional e escala por Velocidade.

### Ataque conjunto (`JointAttack`)

Escolhe aliados para atacar o alvo da habilidade com seu ataque básico, causando o dano completo do ataque básico.

- **Quantidade (`count`):** número de aliados escolhidos; `0` significa todos.
- Com `LowestAlly`, `HighestAlly` ou `RandomAlly`, é escolhido um aliado sem incluir quem lançou a habilidade.
- Aliados que perderam o turno não participam.
- Os ataques básicos realizados por este efeito não acionam outros ataques conjuntos.
- Se um desses ataques derrubar um inimigo, isso conta como abate para a habilidade.

### Turno extra ao derrubar (`ExtraTurnOnKill`)

Se a habilidade já tiver derrubado alguém, quem a lançou recebe imediatamente um turno extra. Coloque este efeito **depois do efeito de dano** para que ele possa verificar o abate.

- **Redução da recarga (`turns`):** quantidade de turnos removidos da recarga; o padrão é `1`.
- Só pode ser ativado uma vez por habilidade.
- O alvo deve ser `Self`.

### Reviver aliados (`Revive`)

Faz aliados caídos voltarem imediatamente com uma parte da Vida máxima. O valor também recebe o bônus de cura da habilidade.

- **Potência (`power`):** fração da Vida máxima com que cada aliado retorna. Por exemplo, `0.3` significa 30%.
- **Quantidade (`count`):** quantos aliados caídos serão escolhidos aleatoriamente; `0` significa todos.
- O cálculo pode usar atributo-base, termos adicionais, multiplicador condicional e escala por Velocidade.
- Aliados que já estejam prestes a reviver sozinhos no próprio turno por causa de uma Passiva não são escolhidos.

Este efeito usa o alvo `AllAllies`.

## 4. Status disponíveis

Os status negativos podem ser barrados por **Resistência** e **Imunidade**, e removidos por **Purificar**. Os positivos podem ser barrados por **Karma** e roubados por **Roubar efeito positivo**, quando aplicável.

| Status (identificador) | Nome | Tipo | Efeito |
|---|---|---|---|
| `Shield` | Escudo | Positivo | Absorve dano até o valor do escudo criado pelo efeito Escudo. |
| `Affliction` | Aflição | Negativo | No começo de cada turno, perde 5% da Vida máxima por cópia. Acumula até 10 cópias por monstro. |
| `Stun` | Atordoamento | Negativo | Faz perder o turno. |
| `Taunt` | Provocação | Negativo | O alvo só pode mirar em quem o provocou. |
| `Hidden` | Oculto | Positivo | Não pode ser escolhido como alvo de ataques únicos. |
| `Curse` | Maldição | Negativo | Faz receber 25% a mais de dano. |
| `Blind` | Cegueira | Negativo | Cada golpe tem 50% de chance de errar. |
| `Aegis` | Égide | Positivo | Anula o próximo golpe recebido. |
| `Foresight` | Presságio | Positivo | O próximo golpe causado é crítico. |
| `Immunity` | Imunidade | Positivo | Impede que efeitos negativos sejam aplicados. |
| `AttackUp` | Ataque+ | Positivo | Aumenta o Ataque em 50%. |
| `AttackDown` | Ataque− | Negativo | Reduz o Ataque em 50%. |
| `DefenseUp` | Defesa+ | Positivo | Aumenta a Defesa em 70%. |
| `SpeedUp` | Velocidade+ | Positivo | Aumenta a Velocidade em 30%. |
| `DefenseBreak` | Defesa− | Negativo | Reduz a Defesa em 70%. |
| `Bomb` | Bomba | Negativo | Ao terminar a contagem, explode causando 250% do Ataque de quem a aplicou, ignora Defesa e também atordoa. |
| `SpeedDown` | Velocidade− | Negativo | Reduz a Velocidade em 50%. |
| `CritUp` | Crítico+ | Positivo | Adiciona 30 pontos percentuais à chance de crítico. |
| `CritResist` | Resistir Crítico | Positivo | Reduz pela metade a chance de os golpes recebidos serem críticos. |
| `Blessing` | Bênção | Positivo | No começo de cada turno, recupera 15% da Vida máxima. Ferida impede a cura. |
| `Counter` | Contragolpe | Positivo | Revida com o ataque básico, causando 75% do dano, sempre que uma habilidade inimiga o atinge. |

| `Karma` | Karma | Negativo | Impede efeitos positivos, incluindo escudos e efeitos roubados. |
| `Sleep` | Sono | Negativo | Faz perder turnos até a duração acabar ou até o alvo receber um golpe. |
| `Unrecoverable` | Ferida | Negativo | Impede receber cura, incluindo dreno e Bênção. |
| `Silence` | Silêncio | Negativo | Só permite usar habilidades sem recarga. |
| `Oblivion` | Esquecimento | Negativo | Desativa a Passiva. Os conjuntos de runas continuam funcionando. |

## 5. Passivas

As Passivas usam um **tipo** e um **valor**. As Passivas genéricas executam os efeitos configurados na habilidade passiva (incluindo efeitos despertos, quando houver). As que verificam status usam também uma configuração de escopo e/ou uma lista de status.

| Passiva (identificador) | O que faz |
|---|---|
| `SpeedWhenLowest` | Concede Velocidade adicional enquanto o dono for o aliado com menos Vida. O valor define a Velocidade adicional. |
| `RebirthOnce` | Permite renascer uma vez; o valor define a Vida ao voltar. |
| `DamageReduction` | Reduz o dano recebido em cada golpe. O valor define a redução. |
| `BonusVsWounded` | Aumenta o dano contra alvos com menos de 50% da Vida. O valor define o bônus. |
| `ImpetoAtWaveStart` | Define o Ímpeto mínimo no início de cada onda. `0.5` equivale a 50 pontos. |
| `CooldownEachTurn` | No começo do turno, existe uma chance de reduzir as recargas. O valor define a chance. |
| `Thorns` | Devolve a quem ataca uma fração do dano recebido. O valor define a fração. |
| `Lifesteal` | Recupera como Vida uma fração de todo dano causado. O valor define a fração. |
| `Dodge` | Dá uma chance de esquivar de cada golpe. O valor define a chance. |
| `CleanseAllyEachTurn` | No começo do turno, existe uma chance de remover um efeito negativo de um aliado. O valor define a chance. |
| `BonusVsStatusOrEffect` | Aumenta o dano contra quem possui status ou efeitos que correspondam aos critérios configurados. O valor define o bônus. |
| `StatusOrEffectOnHit` | Aplica os efeitos configurados a cada alvo atingido que continue de pé; uma vez por habilidade. O alvo dos efeitos é quem foi atingido. |
| `StatusOrEffectOnAttacker` | Aplica os efeitos configurados a quem atingir o dono da Passiva; uma vez por habilidade. O alvo dos efeitos é o atacante. |
| `StatusOrEffectEachTurn` | Aplica os efeitos configurados no começo de cada turno do dono. |
| `StatusOrEffectOnWaveStart` | Aplica os efeitos configurados no começo de cada onda. |
| `StatusOrEffectOnDeath` | Quando o dono cai, aplica os efeitos configurados aos aliados que continuam de pé. |
| `StatusOrEffectWhenLowest` | No começo do turno do dono, aplica os efeitos configurados se ele for o aliado com menos Vida. |
| `ForEachStatusOrEffectAppliedDo` | Executa os efeitos configurados para cada efeito que o dono aplicar, seja novo ou renovado. O alvo é quem recebeu o efeito. |
| `ForEachStatusOrEffectReceivedDo` | Executa os efeitos configurados para cada efeito recebido pelo dono. O alvo é quem aplicou o efeito. |
| `StatusOrEffectOnTargetEachTurn` | Depois de cada turno do dono, aplica os efeitos configurados ao alvo da habilidade. |
| `Undying` | Passiva especial do Chefe Rei Ossudo: enquanto ele estiver em campo, ninguém ganha nem perde Ímpeto. Executa os efeitos configurados depois de cada ação dele (o escudo). O valor define a Vida com que ele retorna sempre que cai. Esquecimento desativa a Passiva, e quem cai sob Esquecimento não retorna. |

## 6. Como os valores são calculados

Dano, cura, escudo e reviver usam uma fórmula geral:

**Potência × atributo-base**, somada aos termos adicionais e ajustada pelos multiplicadores condicionais e pela Velocidade.

Os atributos usados por padrão são:
- **Dano:** Ataque de quem lança.
- **Cura, cura de equipe e reviver:** Vida máxima do alvo.
- **Escudo:** Vida máxima de quem lança.

É possível substituir o atributo padrão por outro.

### Atributos disponíveis

| Atributo (identificador) | Significado |
|---|---|
| `Attack` | Ataque de quem lança. |
| `Defense` | Defesa de quem lança. |
| `MaxHealth` | Vida máxima de quem lança. |
| `Speed` | Velocidade de quem lança. |
| `TargetMaxHealth` | Vida máxima do alvo. |
| `Level` | Nível de quem lança. A potência representa o valor por nível; por exemplo, `110` significa 110 por nível. |

### Termos adicionais

O campo `plus` permite somar um ou mais termos baseados em atributos. Os bônus de nível de dano e cura também se aplicam à potência e a esses termos.

### Multiplicadores condicionais

O multiplicador `factor` usa a fórmula **base + inclinação × fração escolhida**.

| Fração (identificador) | O que mede |
|---|---|
| `HealthFraction` | Fração da Vida atual de quem lança, de 0 a 1. |
| `TargetHealthFraction` | Fração da Vida atual do alvo, de 0 a 1. |
| `LivingAllies` | Quantidade de aliados de pé expressa como fração de 0 a 1; quem lança conta como aliado. |

### Escala por Velocidade

O campo `speed` permite ajustar o cálculo com a Velocidade. Pode somar um valor à Velocidade antes de dividir por um divisor configurado. Com a opção `overTarget: true`, o divisor passa a ser a Velocidade do alvo.

### Observações de balanceamento

O BVP não avalia a fórmula personalizada. Habilidades que usam esses cálculos precisam ser balanceadas manualmente; o editor mostra o valor calculado para cada variante.

## 7. Opções de comparação e escopo

### Característica para escolher o aliado (`by`)

Usada por `LowestAlly` e `HighestAlly`.

| Opção | O que compara |
|---|---|
| `Health` | Fração de Vida. É o padrão. |
| `Attack` | Ataque atual. |
| `Defense` | Defesa atual. |
| `Speed` | Velocidade atual. |
| `Crit` | Chance de crítico. |
| `CritDamage` | Dano crítico. |
| `Resistance` | Resistência. |
| `Accuracy` | Precisão. |
| `Impeto` | Ímpeto acumulado. |

### Escopo dos efeitos (`scope`)

| Opção | O que inclui |
|---|---|
| `All` | Todos os efeitos. |
| `Buffs` | Apenas efeitos positivos. |
| `Debuffs` | Apenas efeitos negativos. |

### Tipo de bônus (`bonus`)

| Opção | Resultado |
|---|---|
| `Damage` | Adiciona potência de dano por efeito contado aos golpes seguintes da mesma habilidade. Por exemplo, `0.2` equivale a +20% por efeito. |
| `Heal` | Adiciona potência de cura e escudo por efeito contado aos efeitos seguintes da mesma habilidade. |
| `Impeto` | Adiciona pontos de Ímpeto por efeito contado, imediatamente, aos alvos do efeito. |

## 8. Exemplos de referência

Os exemplos abaixo ilustram combinações de configuração. Os nomes técnicos são mantidos para facilitar a correspondência com o editor.

**Dano baseado na Defesa, escalando com a Vida restante de quem lança**
```json
{
  "kind": "Damage",
  "power": 1,
  "stat": "Defense",
  "factor": {
    "by": "HealthFraction",
    "base": 8.5,
    "slope": -3
  }
}
```

**Três golpes com ajuste pela Velocidade em relação ao alvo**
```json
{
  "kind": "Damage",
  "power": 1.8,
  "speed": {
    "add": 80,
    "overTarget": true
  },
  "hits": 3
}
```

**Escudo para todos os aliados baseado no nível**
```json
{
  "kind": "Shield",
  "target": "AllAllies",
  "power": 110,
  "stat": "Level",
  "turns": 2
}
```

**Reviver com Vida proporcional à Vida restante de quem lança**
```json
{
  "kind": "Revive",
  "target": "AllAllies",
  "power": 0.5,
  "factor": {
    "by": "HealthFraction",
    "base": 0,
    "slope": 1
  }
}
```

**Dano fixo**
```json
{
  "kind": "Damage",
  "power": 2,
  "fixed": true
}
```

## Consulta rápida

- **Impedir status negativos:** Imunidade.
- **Impedir efeitos positivos:** Karma.
- **Remover um efeito negativo:** Purificar.
- **Impedir cura:** Ferida.
- **Reduzir a duração de efeitos:** Alterar duração com um número negativo de turnos.
- **Prolongar efeitos:** Alterar duração com um número positivo de turnos.
- **Roubar um efeito positivo:** Roubar efeito positivo; se não houver efeito, pode ser configurado para roubar Ímpeto.
- **Conceder turno extra após um abate:** Turno extra ao derrubar, colocado depois do dano.
- **Atacar junto com aliados:** Ataque conjunto.
- **Reviver aliados caídos:** Reviver aliados.
